We need to identify high-risk customers based on recent usage drops. Can you generate a query to find users whose activity in the `usage_logs` table has dropped by more than 50% in the last 30 days compared to the previous 30 days?

smart_toy QueryMind

Certainly. I have formulated a PostgreSQL query to calculate the usage drop for each customer. It uses Common Table Expressions (CTEs) to separate the current 30-day period from the preceding 30-day period.

PostgreSQL 
WITH current_period AS (
    SELECT customer_id, COUNT(*) as current_usage
    FROM usage_logs
    WHERE event_date >= CURRENT_DATE - INTERVAL '30 days'
    GROUP BY customer_id
),
previous_period AS (
    SELECT customer_id, COUNT(*) as previous_usage
    FROM usage_logs
    WHERE event_date >= CURRENT_DATE - INTERVAL '60 days'
      AND event_date < CURRENT_DATE - INTERVAL '30 days'
    GROUP BY customer_id
)
SELECT 
    p.customer_id,
    p.previous_usage,
    COALESCE(c.current_usage, 0) as current_usage,
    ROUND((1.0 - (COALESCE(c.current_usage, 0)::numeric / p.previous_usage)) * 100, 2) as drop_percentage
FROM previous_period p
LEFT JOIN current_period c ON p.customer_id = c.customer_id
WHERE p.previous_usage > 10 
  AND (COALESCE(c.current_usage, 0)::numeric / p.previous_usage) < 0.5
ORDER BY drop_percentage DESC;

Note: I added a condition `p.previous_usage > 10` to filter out noise from customers who had very low baseline usage.
