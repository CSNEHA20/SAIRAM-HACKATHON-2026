# Evaluation Criteria

| Criteria | Weight | Description |
|----------|--------|-------------|
| **Functionality** | 30% | All required tools working, accurate query generation |
| **Tool Design & Architecture** | 25% | Clean tool schemas, modular design, extensibility |
| **Visualization Quality** | 20% | Chart clarity, appropriate visualization choices, aesthetics |
| **User Experience** | 15% | Chat interface, responsiveness, error handling UX |
| **Innovation & Creativity** | 10% | Novel features, creative solutions, bonus challenges |
