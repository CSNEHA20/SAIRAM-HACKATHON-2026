# Submission Guidelines

## 8.1 Required Deliverables
1. **Source Code:** Complete codebase in a Git repository
2. **README.md:** Setup instructions, architecture overview, tool documentation
3. **Demo Video:** 3-5 minute walkthrough demonstrating key features
4. **Live Demo:** Working deployment or ability to run locally during judging

## 8.2 Code Requirements
- Clean, well-commented code following best practices
- Environment configuration via `.env` file (no hardcoded API keys)
- Docker support preferred for easy deployment
- Unit tests for critical tool functions (bonus)
