Analyze the recent spike in churn for the enterprise segment in Q3. I need a query to extract the key usage metrics for customers who downgraded, specifically focusing on API call volume drops prior to cancellation.

psychology QueryMind

I have analyzed the enterprise segment parameters for Q3. The primary indicator of churn appears to be a precipitous drop in `api_v2_calls` approximately 14 days before the formal downgrade event.

Here is the optimal SQL syntax to extract this cohort, cross-referencing the usage logs with the billing events table:

PostgreSQL 
WITH ChurnedUsers AS (
    SELECT account_id, downgrade_date
    FROM billing_events
    WHERE event_type = 'downgrade' 
      AND segment = 'enterprise'
      AND date_part('quarter', downgrade_date) = 3
)
SELECT 
    c.account_id,
    AVG(u.api_v2_calls) AS avg_calls_prior_14d,
    AVG(u.api_v2_calls_prev_month) AS baseline_calls
FROM ChurnedUsers c
JOIN usage_logs u ON c.account_id = u.account_id
WHERE u.log_date BETWEEN (c.downgrade_date - INTERVAL '14 days') 
                  AND c.downgrade_date
GROUP BY c.account_id
HAVING AVG(u.api_v2_calls) < ( AVG(u.api_v2_calls_prev_month) * 0.5 );
